# Controllable Poisson–Arago Spot via Phase-Selective Obstruction of Radial Carpet Beams

This repository contains the MATLAB code used for simulations, data analysis, and figure generation in the paper:

> **"Controllable Poisson–Arago spot via phase-selective obstruction of radial carpet beams"**
> Mohaddeseh Mohammadi Masouleh, Somaye Fathollazade, Saifollah Rasouli
> (2026)

The paper demonstrates a power-controllable Poisson–Arago spot generated by phase-selective amplitude filtering of radial carpet beams (RCBs): a beam produced by diffraction from a binary radial phase grating ($m_1$ spokes) is passed through a coaxial binary amplitude radial grating ($m_2$ spokes) that selectively transmits in-phase sectors, producing a controllable on-axis spot when the spoke-number ratio is an odd integer. The code in this repository covers the full computational pipeline behind this result, from beam generation through experimental calibration and multi-level power quantification.

## Repository Structure

```
code/
├── 01_initial_idea/                                     # Fig. 1
├── 02_generation_initial_idea_with_normalization/       # Fig. 2
├── 02_generation_initial_idea_without_normalization/    # Visualizations 1 & 2
├── 03_slm_characterization/                             # Supplement, Sec. 2
├── 04_intensity_detection_plane/                        # Fig. 4
├── 05_phase_patterns_second_grating/                    # Fig. 5
├── 06_power_in_phase_regions/                           # Supplement, Sec. 3
├── 07_calibration_theta_effect/                         # Supplement, Sec. 4; Visualization 3
└── 08_power_of_spots/                                   # Fig. 6
```

- **`01_initial_idea/`** — Generates the binary radial phase and amplitude gratings and the resulting RCB intensity/phase cross-sections, reproducing **Fig. 1** of the main manuscript.

- **`02_generation_initial_idea_with_normalization/`** — Simulates free-space and lens-assisted propagation of the filtered beam and the normalized intensity patterns used in **Fig. 2** of the main manuscript.

- **`02_generation_initial_idea_without_normalization/`** — Companion unnormalized version of the above propagation simulations, also underlying **Visualizations 1 and 2**.

- **`03_slm_characterization/`** — Characterizes the non-ideal, phase-mostly response of the spatial light modulator (SLM), used for **Section 2 of the Supplemental Document**. Includes: generation of binary SLM patterns; simulation of beam profiles for different amplitude/phase visibility parameters ($V_a$, $V_p$); and profile analysis comparing simulated patterns against experimentally recorded ones (stored in the `preimages` subdirectory) to determine the best-fit SLM parameters.

- **`04_intensity_detection_plane/`** — Generates simulated intensity patterns at the detection plane for various $(m_1, m_2)$ combinations, reproducing **Fig. 4** of the main manuscript.

- **`05_phase_patterns_second_grating/`** — Computes the simulated phase distributions immediately after the amplitude grating for the same $(m_1, m_2)$ combinations as Fig. 4, reproducing **Fig. 5** of the main manuscript.

- **`06_power_in_phase_regions/`** — Performs the statistical phase/power analysis of the transmitted sectors (main intensity spot and tail), verifying that both remain predominantly in-phase. Generates the figures and tables in **Section 3 of the Supplemental Document**.

- **`07_calibration_theta_effect/`** — Simulates the effect of relative angular rotation ($\theta$) between the phase and amplitude gratings on the transmitted and on-axis intensity, producing **Section 4 of the Supplemental Document** and **Visualization 3**, and demonstrating the periodic calibration method.

- **`08_power_of_spots/`** — Quantifies the normalized power density of the Poisson–Arago spot across different $m_1$ values, reproducing **Fig. 6** of the main manuscript, and supporting the multi-level optical encoding scheme described in the paper.

## Requirements

- MATLAB R2020a or later
- Toolboxes: Image Processing Toolbox, Signal Processing Toolbox

## Usage

Each subfolder is self-contained. Navigate to the desired subfolder and run `main.m`:

```matlab
cd code/01_initial_idea
main
```

Each subfolder regenerates the corresponding figure(s) or supplementary result listed above.
